Test Information and Study Materials

Effective R-11 exam preparation should combine trade review, code study, safety review, electrical calculation practice, fire alarm review, photovoltaic system study, and open-book navigation practice. Students should begin by learning what each book is used for. OSHA supports safety questions. The National Electrical Code supports the largest portion of electrical code review. NFPA 72 supports fire alarm and signaling topics. Ugly's Electrical References supports formulas, tables, and calculation support. Photovoltaic Systems supports solar electric concepts and PV system fundamentals.

For safety topics, spend time with OSHA 29 CFR Part 1926. Electrical work can involve ladders, elevated work areas, hand tools, power tools, temporary power, trenching, material handling, personal protective equipment, hazard communication, and general construction site hazards. Safety questions can be direct, so students should know how to locate OSHA rules quickly.

For NEC topics, review definitions, wiring methods, conductor sizing, conductor ampacity, box fill, raceway fill, grounding and bonding, service equipment, feeders, branch circuits, overcurrent protection, receptacle placement, GFCI protection, AFCI protection, equipment installation, working clearances, and dwelling-unit requirements. For fire alarm and signaling topics, review system terminology, initiating devices, notification appliances, power supplies, circuit concepts, installation requirements, inspection awareness, and common fire alarm system components. Students should understand how to locate information in NFPA 72 even when a question uses unfamiliar terminology.

For electrical math topics, practice calculations involving Ohm’s law, power, voltage, current, resistance, conductor sizing, voltage drop awareness, box fill, raceway fill, load calculations, and unit conversions. Ugly's Electrical References can help students quickly review formulas, symbols, and tables that support calculation-based questions.

For photovoltaic topics, review PV modules, arrays, inverters, conductors, disconnects, grounding, system layout, sunlight and shading effects, installation safety, and basic troubleshooting concepts. Photovoltaic questions may test both system knowledge and the ability to recognize PV-specific terminology.
