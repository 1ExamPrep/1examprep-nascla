# NASCLA product data from Shopify

Pulled from the 1 Exam Prep store on 2026-10-18. Every product with "NASCLA" in its title.

- `nascla-products.json`: all 465 products, full data (description HTML, SEO, variants with SKU/price/inventory, tags, collections, image, URL).
- `nascla-products.csv`: one row per product, same data minus the description. Opens in Excel.
- `nascla-collections.json`: the 183 collections those products sit in, with how many NASCLA products each holds.

Status: 454 active, 11 draft.

Note: a plain "nascla" search in Shopify matches 1,793 products, because many only mention NASCLA in the description. Those are not included here.
